## Install

    pipx install .

Requires Python 3.11+. External tools are optional per module: binwalk, unsquashfs
(or sasquatch), hashcat, radare2.

## Usage

    textolit init ./case-foo --image firmware.bin
    textolit unpack ./case-foo
    textolit entropy ./case-foo
    textolit fswalk ./case-foo          # index every file, flag anomalies
    textolit binintel ./case-foo        # ELF arch, libs, version fingerprints
    textolit netmap ./case-foo          # listen-by-default table with source lines
    textolit findings ./case-foo        # leads pending review
    textolit decide ./case-foo 4 reject --note "lab placeholder"
    textolit report ./case-foo          # Markdown, grouped by OWASP IoT Top 10
    textolit tui ./case-foo

`fswalk`, `binintel` and `netmap` each queue the rule sweep (`missedfindings`) when they
finish; the CLI runs it before returning, the TUI runs it in the background.

Cases are directories: `case.db` (SQLite, WAL) plus `artifacts/`. Relaunching resumes
from the database. LLM use is off by default and toggled per case. Extraction runs under
`umask 0` so file modes in the report are the image's, not the analyst's.

## Rule packs

YAML packs in `src/textolit/rules/` (`creds`, `services`, `files`); extra packs load with
`textolit missedfindings ./case --rules-dir DIR`. Kinds: `content`, `path`, `perm`, `magic`.
Every hit becomes a finding with a confidence and an evidence path. Rejections are kept.
